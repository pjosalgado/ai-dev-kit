# BMad Default Template

BMad Method template with pre-configured agents, skills, and project-level customizations.

## What's Included

| Module | Purpose |
|--------|---------|
| BMM | Core software development workflow |
| BMB | Skills and workflow builder |
| CIS | Creative Intelligence Suite |
| TEA | Test Engineering & Architecture |
| BMAD Loop | Automation orchestrator |

## Customizations

- **`AGENTS.md`** — First-step prompt to detect user intent (customize or develop in a project)
- **`_bmad/custom/bmad-project-context.toml`** — Configurable design patterns applied during project documentation

## Quick Start

The agent will ask whether you want to:
1. Customize an agent/skill in this repository
2. Develop in your project using these agents/skills
