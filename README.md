# AI Development Kit

A toolkit for building AI-powered software development workflows.

## What is BMad?

**BMad Method** is the core framework here. It turns generic AI assistants into specialized collaborators using:

- **Agents** — Focused personas (PM, Architect, Designer, Developer, Tester)
- **Skills** — Reusable instructions and workflows
- **Workflows** — Automated multi-step processes

## Modules

| Module | Purpose |
|--------|---------|
| BMM | Core development workflow |
| BMB | Skills and workflow builder |
| CIS | Creative Intelligence Suite |
| TEA | Test Engineering & Architecture |
| BMAD Loop | Automation orchestrator |

## Quick Start

1. Clone this repository into your project
2. Run your agent — it will ask whether you want to:
   - Customize an agent/skill
   - Develop in your project

## Customizations

- **`AGENTS.md`** — Detects user intent
- **`_bmad/custom/bmad-project-context.toml`** — Design patterns for documentation
