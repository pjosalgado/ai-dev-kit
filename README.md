# AI Development Kit

A toolkit for building AI-powered software development workflows. Main topics: **BMad** (structured development methodology) and repo **Customizations**.

## BMad

**BMad Method** is the core framework — it turns a generic AI assistant into an AI-powered development team. You work with specialized agents (PM, Architect, Developer, Tester) through reusable skills and multi-step workflows that cover the full delivery cycle, from requirements to tested code.

| Module | Purpose |
|--------|---------|
| BMM | Core development workflow |
| BMB | Skills and workflow builder |
| CIS | Creative Intelligence Suite |
| TEA | Test Engineering & Architecture |
| BMAD Loop | Automation orchestrator |

## Customizations

- **`AGENTS.md`** — Detects user intent
- **`_bmad/custom/`** — Folder for BMad customizations (project context, configuration)

## Quick Start

1. Clone this repository into your project
2. Run your agent — it will ask whether you want to:
   - Customize an agent/skill
   - Develop in your project
